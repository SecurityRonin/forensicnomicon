# Privacy Policy

*Last updated: 2026-06-15*

## Summary

forensicnomicon is a local Rust library and CLI. It does not collect, transmit, or store any personal data on remote servers.

## Data Access

forensicnomicon reads only the input you pass to it. The catalog is compiled in; all processing happens in memory on your local machine. Nothing is uploaded anywhere.

## Telemetry

forensicnomicon has **no telemetry**. It makes no network requests of any kind.

## Open Source

forensicnomicon is open source (Apache-2.0). You can audit every line of code at [github.com/SecurityRonin/forensicnomicon](https://github.com/SecurityRonin/forensicnomicon).
